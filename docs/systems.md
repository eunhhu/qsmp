# 시스템 전체 목록과 사용법

현재 서버에 적용된 콘텐츠, QoL, 운영 도구를 모두 정리합니다.

## 월드 생성과 탐험

데이터팩:

- `Terralith 2.6.2`: 오버월드 바이옴과 자연 지형 확장
- `Terratonic 3.0.22`: Terralith 지형을 더 큰 산맥/협곡 스타일로 조정
- `Continents 1.1.13`: 대륙과 넓은 바다 생성
- `Dungeons and Taverns 5.2.0`: 던전, 주점, 전투 구조물
- `Explorify 1.6.5`: 바닐라풍 탐험 구조물
- `Structory 1.3.15`: 폐허, 탑, 정착지 등 풍경 구조물
- `Nullscape 1.2.18`: 엔드 지형 개편
- `True Ending 1.1.4d`: 엔더 드래곤 전투와 엔딩 연출 개편
- `True Ending 26 Compat`: 26.1 `time_check` predicate 호환 패치
- `QSMP Rules`: 온라인 인원 50% 수면으로 밤 넘김

사용법:

- 새 지형/구조물은 새 청크에서만 보입니다.
- 이미 생성된 청크는 바뀌지 않습니다.
- `/locate biome`는 지형 팩 때문에 서버를 멈칫하게 할 수 있으니 플레이 중 남발하지 않습니다.

탐험 공략 콘텐츠:

- `Frontier Compass` 일반 우클릭: 야외 전쟁 레이드 전장 추적
- `Frontier Compass` 웅크린 우클릭: 봉인 유적 탐험 추적
- 자연 구조물은 풍경과 loot 중심이고, 봉인 유적은 목표/매복/해제/보상 중심입니다.

## QSMP Codex와 게임 내 안내

플러그인: `QSMPFrontier`

첫 접속 지급:

- `Frontier Compass`
- `QSMP Codex`
- 커스텀 제작법 전체 자동 해금

`QSMP Codex` 사용:

- 일반 우클릭: 책으로 읽기
- 웅크린 우클릭: 아이콘 GUI 열기
- GUI 아이콘 클릭: 전장 추적, 유적 추적, Survivor 확인, Legacy 확인, 인챈트/모루 규칙, 거점 제작법 재해금, 엔드 레이드 요약, 리소스팩 안내
- `Battle Readiness`: 현재 Survivor 레벨/XP/남은 스탯과 메인핸드 Legacy 상태 요약
- `Survivor Level`: 현재 레벨, XP 바, 남은 스탯 포인트, 주력 스탯 표시
- `Legacy Gear`: 들고 있는 장비의 Legacy 레벨, XP, 기록, 보너스 표시

해금되는 제작법:

- `Tactical Whistle`
- `Frontier Compass`
- `QSMP Codex`
- 모든 자원 거점 코어
- Tier II/Tier III 업그레이드 키트

Codex 재제작:

```text
Book + Amethyst Shard + Copper Ingot
```

의도:

- 친구들이 명령어를 외우지 않아도 진행 축을 알 수 있습니다.
- 전장/유적은 나침반으로 찾고, 성장/장비는 GUI 아이콘으로 확인합니다.
- 제작법은 기본 잠금 해제 상태라 레시피북에서 바로 검색할 수 있습니다.
- 인챈트 상한, 리소스팩, 엔드 공략처럼 텍스트로 묻기 쉬운 규칙도 Codex GUI에서 바로 확인합니다.

연출 설정:

```yaml
cinematics:
  enabled: true
  compass-trails: true
```

- `enabled`: 패링, 구르기, 동료 역할, 거점, 유적, 워프론트, 드래곤 연출 전체
- `compass-trails`: `Frontier Compass`를 들고 이동할 때 짧은 길잡이 파티클 표시

## QSMP 전용 리소스팩

상태: 필수 리소스팩 적용.

역할:

- 현실풍 64px 절차 생성 텍스처
- 워프론트/유적에 많이 쓰이는 심층암, 흑석, 우는 흑요석, 자석석, 배럴 질감 강화
- Codex, 나침반, 보상 재료 등 주요 아이템 질감 강화
- 버튼/슬롯 UI sprite 강화
- 전쟁 나팔, 드래곤, 공명석, 패링, vault 사운드에 바닐라 고품질 사운드 레이어 추가

서버 설정:

```properties
require-resource-pack=false
resource-pack=https://cdn.modrinth.com/data/ZltblCOt/versions/uTOUpxTI/true-ending-dragon-music-v1.zip
resource-pack-sha1=93aaaacdde99601ad519e1970255e52be8a09b0e
```

동작:

- `./server.sh start`는 generated QSMP pack을 기본으로 빌드하지 않습니다.
- 서버는 True Ending 공식 음악팩을 optional pack으로 제안합니다.
- 거부/다운로드 실패 시에도 접속은 유지됩니다.

주의:

- True Ending 음악팩은 Modrinth CDN URL과 SHA1을 [server.properties](../server.properties)에 고정합니다.
- generated QSMP pack을 다시 쓰려면 [server.env](../server.env)의 `RESOURCE_PACK_ENABLED=true`와 공개 URL을 별도로 설정합니다.

## QSMPFrontier 전투

목표: 바닐라 전투에 아크식 기동성과 방어 타이밍을 추가합니다.

패링:

- 조건: 방패를 메인핸드 또는 오프핸드에 든 상태
- 입력: 손 바꾸기 키 기본 `F`
- 판정 시간: 425ms
- 쿨다운: 1800ms
- 성공 효과: 피해 무효, 투사체 반사 또는 근접 적 넉백/빙결

구르기:

- 조건: 달리는 중, 땅 위, 비행 아님
- 입력: 웅크리기 시작
- 무적 시간: 475ms
- 쿨다운: 2600ms

연출:

- 패링 준비 때 방패 주변에 짧은 신호음과 입자 표시
- 완벽 패링 성공 때 적 위치에 충격파, 금속음, 넉백 시각화
- 구르기 때 바닥 먼지/바람 궤적 표시
- 회피 무적이 실제로 피해를 씹었을 때 별도 회피 피드백 표시

## QSMPFrontier 동료 역할

플레이어 직업 시스템은 없습니다. 직업처럼 보이는 것은 동료 역할이고,
플레이어 본체 성장은 별도 `Survivor Level`입니다.

역할:

- `Vanguard`: 동료 공격 피해 1.35배, 받는 피해 22% 감소
- `Ranger`: 표적에게 45틱마다 6 피해 화살 지원
- `Medic`: 80틱마다 주인과 주변 동료를 4 회복
- `Gatherer`: 채집 추가 드롭, 자원 거점 생산 증가

사용법:

```text
Tactical Whistle 우클릭: 역할 순환
Tactical Whistle로 내 동료 우클릭: 역할 배정
```

연출:

- 역할 배정 시 동료 위에 역할색 입자와 확인음 표시
- `Ranger` 지원 사격은 화살 궤적을 더 잘 보이게 표시
- `Medic` 회복은 주변 동료/주인에게 초록 파동으로 표시

휘슬 조합:

```text
 . C .
 G H G
 . R .
```

- `C`: 구리 주괴
- `G`: 금 주괴
- `H`: 염소 뿔
- `R`: 레드스톤

## QSMPCompanions 동료 성장

지원 대상:

- 길들인 바닐라 동물
- Ghast Bonding Charm으로 결속한 Happy Ghast

성장:

- 최대 레벨: 30
- 기본 다음 레벨 경험치: 50
- 레벨당 필요 경험치 증가: 25
- 적대 몹 처치 경험치: 15
- 경험치 공유 반경: 24블록
- 레벨당 최대 체력 +4%
- 레벨당 공격력 +3%

전투:

- 주인이 적대 몹을 때리면 근처 동료가 추적합니다.
- 주인이 공격받아도 근처 동료가 개입합니다.
- 앉은 동료와 탑승 중인 동료는 추적하지 않습니다.
- 주인과 동료는 서로 피해를 줄 수 없습니다.

확인:

```text
/companion info
```

또는 빈손으로 웅크린 채 내 동료 우클릭.

## Survivor Level

플러그인: `QSMPFrontier`

바닐라 경험치 레벨과 별개인 영구 성장입니다.

확인:

```text
/survivor
/frontier survivor
```

성장:

- MVP 최대 레벨: 30
- 레벨업마다 스탯 포인트 1
- 10레벨마다 특성 포인트 1 저장
- 리스펙 1회 무료, 이후 메아리 조각 1개 필요

스탯:

- `Might`: 공격 피해 증가
- `Endurance`: 최대 체력 증가, 받는 피해 감소
- `Agility`: 구르기 쿨다운 감소, 이동/낙하 보정
- `Wisdom`: 장비 Legacy XP 획득량 증가
- `Command`: 자원 거점 생산 효율 증가

사용:

- Frontier Codex를 들고 웅크린 채 우클릭하면 Codex GUI가 열립니다.
- Codex의 `Survivor Level`을 누르거나 `/survivor`를 실행하면
  `Survivor Core` GUI가 열립니다.
- `Survivor Core` 상단에는 XP 획득 경로와 현재 전투 스탯 판독 아이콘이 따로 있습니다.
- `Might`, `Endurance`, `Agility`, `Wisdom`, `Command` 아이콘을 클릭하면
  남은 스탯 포인트가 바로 투자됩니다.
- `Respec` 아이콘은 1회 무료 초기화, 이후 메아리 조각 1개를 소모합니다.

Survivor XP 획득:

- 워프론트 승리
- 봉인 유적 vault 보상 획득
- 엔더 드래곤/위더 처치 참여
- 자원 거점 업그레이드
- 자연 스폰 적대몹 사냥
- 광물, 고대 잔해, 자연 석재 계열 채굴
- 원목, 완전히 자란 작물 채집

악용 방지:

- 스포너, 스폰 알, 명령, 커스텀 스폰 몹은 일반 사냥 XP를 주지 않습니다.
- 플레이어가 방금 설치한 광물/원목/석재 계열 블록은 재채굴 XP를 주지 않습니다.
- 일반 석재 계열 채굴 XP는 짧은 쿨다운을 둬 자동 굴착으로 폭증하지 않게 합니다.

체감 피드백:

- 일반 사냥/채굴 XP도 짧은 공명 입자와 낮은 볼륨의 경험치음으로 확인됩니다.
- `Might` 피해 증가는 대상 위치의 치명타 입자로 보입니다.
- `Endurance` 피해 감소는 플레이어 주변 방어 입자와 방패음으로 보입니다.

## 인챈트/모루 상한

플러그인: `QSMPFrontier`

서버 설정: `purpur.yml`

- 스케일형 인챈트는 최대 10레벨까지 유지됩니다.
- `Mending`, `Infinity`, `Flame`, `Silk Touch`, `Aqua Affinity`,
  `Channeling`, `Multishot`, 저주 계열처럼 단일성 인챈트는 1레벨로 유지됩니다.
- 모루는 `Too Expensive` 제한을 사실상 해제하고, 고레벨 인챈트 병합을 직접 보정합니다.
- 모루 누적 작업 비용도 꺼서 오래 쓴 장비가 작업 횟수 때문에 막히지 않게 합니다.
- 같은 레벨끼리 합치면 +1, 서로 다르면 높은 레벨을 유지하며 최대 10에서 멈춥니다.
- 기존 아이템 lore에 남은 `버그 인챈트`/`Bug Enchant`/`Illegal Enchant`
  표기는 접속, 픽업, 모루 사용, 인벤토리 닫기, 주기 점검 때 자동 정리됩니다.
- 정리된 경우 플레이어에게 짧은 액션바와 인챈트 테이블 소리로 알려줍니다.

## Legacy Gear

플러그인: `QSMPFrontier`

무기, 도구, 방어구, 방패가 오래 쓰면 자체 레벨과 기록을 갖습니다.

확인/관리:

```text
/legacy
/frontier legacy
```

- `Legacy Arsenal` GUI가 열리고, 들고 있는 장비의 레벨/XP/기록/강화 상태를
  한 화면에서 확인합니다.
- `Refine`, `Awaken`, `Transfer Memory` 아이콘을 클릭해 상위 성장을 진행합니다.
- Legacy 대상 아이템은 인벤토리에 들어오거나 장착/핫바 이동/픽업되는 즉시
  자동 귀속됩니다. `/legacy bind`는 더 이상 플레이 루프에 필요 없습니다.

상위 성장:

```text
/legacy refine
/legacy awaken
/legacy transfer
```

성장 대상:

- 무기: 검, 도끼, 활, 쇠뇌, 삼지창, 메이스
- 도구: 곡괭이, 도끼, 삽, 괭이, 가위, 낚싯대
- 방어구/장비: 헬멧, 흉갑, 레깅스, 부츠, 겉날개, 방패

XP 획득:

- 무기: 직접 공격, 킬
- 도구: 광석, 고대 잔해, 원목 채집
- 방어구: 피해 흡수
- 레이드/유적/드래곤/위더 보상: 장착 장비에 Legacy XP 지급

효과:

- 최대 Legacy Level: 10
- 무기: 최종 피해, 공격 속도, 내구 보호 확률이 증가합니다.
- 도구: 채굴 속도, 공격 속도, 내구 보호 확률이 증가합니다.
- 방어구/방패/겉날개: 받는 피해 감소와 내구 보호 확률이 증가합니다.
- 모든 보너스는 아이템 lore와 `Legacy Arsenal` GUI에 퍼센트로 표기됩니다.
- `/legacy refine`: 네더라이트 조각을 써서 최대 +5까지 강화합니다. +3부터는 `Void Scale`도 필요합니다.
- Refine은 실패 확률이 있습니다. 실패하면 재료를 잃고 장비 내구도가 손상되지만, 장비는 파괴되지 않고 Legacy XP를 조금 얻습니다.
- Legacy Lv.5 이상부터 낮은 공명 입자, Refine +3 이상부터 더 강한 공명/번개 연출이 붙습니다.
- `/legacy awaken`: 최대 레벨 장비와 `Dragon Heart`로 각성합니다. 각성 장비는 추가 보너스와 전투 중 `Void Burst` 발동 연출/추가 피해를 얻습니다.
- `/legacy transfer`: 메인핸드 Legacy 기억을 오프핸드 장비에 각인합니다. `Memory Shard`가 필요하고 레벨/Refine은 일부 낮아지며 오프핸드 기존 기억은 덮어씁니다.
- lore에 소유자, 킬, 작업, 레이드 기록, 성장 보너스, refine 실패 확률이 남습니다.

## 엔더 드래곤 레이드

플러그인/데이터팩:

- `True Ending 1.1.4d`
- `QSMPFrontier` Dragon 강화 레이어

기본 변화:

- True Ending이 드래곤 공격, 페이즈, 연출을 바꿉니다.
- `QSMPFrontier`가 살아 있는 드래곤을 감지하면 `Awakened Ender Dragon`으로 스케일합니다.
- 근처 레이드 인원 수에 따라 최대 체력과 플레이어가 받는 드래곤 피해가 증가합니다.

공략 규칙:

- 체력 65% 이하: 공명석 3개가 생기고 드래곤 피해가 크게 줄어듭니다.
- 체력 35% 이하: 더 먼 공명석 4개가 생깁니다.
- 공명석은 `Crying Obsidian` + `End Rod` 형태입니다.
- 공명석이 남아 있으면 드래곤에게 들어가는 피해가 25%로 줄어듭니다.

## 봉인 유적 탐험

플러그인: `QSMPFrontier`

- sentinel은 전용 persistent key와 scoreboard tag로 추적하고, 서버 종료 시 정리합니다.
- 유적 생성 시 주변 48블록에서 물/얼음/잎 위를 피하고 땅을 찾아 건설합니다.

- ward는 `Crying Obsidian` 위 `End Rod`로 멀리서도 식별됩니다.

- ward 파괴, vault 해제, vault claim마다 다른 파티클/사운드/타이틀이 표시됩니다.

설정:
