# 플레이어 온보딩

친구들에게 보여줄 실제 플레이 순서입니다. 명령어를 몰라도 진행되게 설계된 시스템이 많습니다.

## 첫 접속

1. 접속하면 `Frontier Compass`를 받습니다.
2. 나침반을 우클릭하면 전장 방향을 잡습니다.
3. 나침반을 들고 웅크린 채 우클릭하면 봉인 유적 방향을 잡습니다.
4. 바로 전장으로 달리기보다 기본 장비, 방패, 침대, 음식, 동료를 먼저 준비합니다.
5. 밤은 온라인 인원의 50%가 자면 넘어갑니다.

## 초반 목표

1. 새 청크 방향으로 탐험합니다.
2. Terralith/Terratonic 지형, Dungeons and Taverns 구조물, Explorify/Structory 구조물을 찾습니다.
3. 늑대, 고양이, 말 등 길들일 수 있는 동물을 확보합니다.
4. 동료와 함께 적대 몹을 잡아서 동료 레벨을 올립니다.
5. `Tactical Whistle`을 만들어 동료 역할을 배정합니다.

## 전투 조작

- 방패를 든 상태에서 손 바꾸기 키 기본 `F`: 패링
- 달리는 중 웅크리기 한 번: 구르기
- 구르기 중 짧은 무적 시간이 있습니다.
- 패링 성공 시 피해를 막고 투사체 반사 또는 근접 적 넉백이 발생합니다.

## 동료 키우기

동료는 길들인 동물 또는 결속한 Happy Ghast입니다.

1. 동물을 길들입니다.
2. 적대 몹과 싸울 때 동료를 근처에 둡니다.
3. 주인이 몹을 죽이면 24블록 안의 가장 가까운 동료가 경험치를 받습니다.
4. 동료가 직접 죽여도 경험치를 받습니다.
5. 동료는 최대 30레벨까지 성장합니다.

동료 확인:

```text
/companion info
```

또는 빈손으로 웅크린 채 내 동료를 우클릭합니다.

## 동료 역할

플레이어 직업은 없습니다. 대신 `Tactical Whistle`로 동료에게 역할을 붙입니다.

- `Vanguard`: 앞라인. 동료 피해 증가, 받는 피해 감소
- `Ranger`: 원거리 지원. 주인이 찍은 대상에게 화살 지원
- `Medic`: 회복 지원. 주인과 주변 동료 회복
- `Gatherer`: 채집/생산. 블록 드롭 보너스, 자원 거점 생산 보너스

사용법:

1. `Tactical Whistle`을 듭니다.
2. 공중이나 블록을 우클릭해 역할을 바꿉니다.
3. 내 동료를 우클릭해 선택한 역할을 배정합니다.

## 동료 보관

`Cryopod`로 동료를 저장하고 다시 꺼낼 수 있습니다.

- 빈 크라이오포드 들고 웅크린 채 내 동료 우클릭: 보관
- 채워진 크라이오포드로 블록 우클릭: 소환
- 소유자만 꺼낼 수 있습니다.

## 자원 거점

자원 거점은 배럴처럼 설치하는 생산 시설입니다.

1. 거점 코어를 만듭니다.
2. 원하는 위치에 설치합니다.
3. 생산물은 해당 배럴 안으로 들어갑니다.
4. 넘친 생산물은 64블록 안의 내 `Warehouse` 또는 공용 `Warehouse`로 이동합니다.
5. Tier II, Tier III 업그레이드 키트로 생산량을 올립니다.

추천 배치:

- `Deep Mine`: y 32 이하
- `Greenhouse`: 위가 밝고 하늘빛이 들어오는 곳
- `Fishery`: 근처에 물이 있는 곳
- `Lumber Camp`: 주변에 나무가 있는 곳
- `Warehouse`: 생산 거점 64블록 안

## 봉인 유적 탐험

구조물 탐험에 공략 목표를 붙인 `QSMPFrontier` 콘텐츠입니다.

1. `Frontier Compass`를 들고 웅크린 채 우클릭합니다.
2. 나침반이 가리키는 유적으로 원정합니다.
3. 주변 청크를 로드하면 작은 폐허와 `Sealed Ruin Vault`가 생깁니다.
4. 폐허 주변의 `Crying Obsidian` ward 3개를 찾습니다.
5. ward를 깨면 `Ruin Sentinel` 매복이 옵니다.
6. ward 3개와 남은 sentinel을 정리하면 vault 봉인이 풀립니다.
7. vault를 우클릭해서 주변 팀원과 보상을 받습니다.

보상:

- 경험치
- 에메랄드
- 경험치 병
- 자수정 조각
- 낮은 확률로 다이아몬드, 메아리 조각, 자원 거점 코어

쿨다운은 90분입니다.

## 야외 전쟁 레이드

`QSMPFrontier`의 메인 레이드입니다.

1. `Frontier Compass`를 우클릭합니다.
2. 나침반이 가리키는 방향으로 원정합니다.
3. 전장 주변 청크를 실제로 로드하면 전장이 자연 지형 위에 건설됩니다.
4. 전장 반경 안에서 15초 머무르면 자동 시작됩니다.
5. 3번의 공격 웨이브, 돌파전, `Iron Tyrant` 보스를 처리합니다.

참가 규칙:

- 전장 주변에 있으면 레이드 참가자로 기록됩니다.
- 중간에 합류해도 참가자로 들어갈 수 있습니다.
- 보스바는 전장 근처 참가자에게 붙습니다.
- 모두 전장을 너무 오래 비우면 레이드는 실패합니다.
- 보상은 전장 근처에 있거나 최근까지 싸운 참가자에게 지급됩니다.

보상:

- 경험치 750
- 에메랄드 12개
- 네더라이트 조각 2개
- 랜덤 자원 거점 코어 1개

쿨다운은 180분입니다.

## 트라이얼 챔버

`TrialChamberPro`가 자연 트라이얼 챔버를 반복 콘텐츠로 바꿉니다.

1. 자연 트라이얼 챔버를 찾습니다.
2. 서버가 자동으로 챔버를 등록합니다.
3. 스포너 웨이브는 보스바로 진행도가 보입니다.
4. 볼트와 상자는 플레이어별 보상입니다.
5. 기본 48시간마다 챔버가 리셋됩니다.
6. 챔버 안에서 죽으면 관전 선택지가 뜹니다.

상태 명령:

```text
/tcp stats
/tcp leaderboard <type>
```

비OP에서 막히면 서버 권한 설정 문제입니다. 운영자에게 확인을 요청합니다.

## 사망과 복구

- 죽으면 사망 지점에 30분짜리 개인 무덤이 생깁니다.
- 아이템은 무덤에 저장됩니다.
- 경험치는 50%만 저장됩니다.
- 본인만 무덤을 열 수 있습니다.
- 30분이 지나면 내용물이 바닥에 떨어집니다.

`/back`, `/home`, `keepInventory`는 기본 흐름에 없습니다. 죽은 곳까지 직접 돌아가야 합니다.

5. Tactical Whistle 제작
6. 동료 역할 배정
7. 자원 거점 하나 설치
8. 봉인 유적 원정
9. 트라이얼 챔버 탐사
10. 전장 원정
11. 레이드 보상으로 거점 확장
