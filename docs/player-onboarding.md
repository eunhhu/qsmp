# 플레이어 온보딩

친구들에게 보여줄 실제 플레이 순서입니다. 명령어를 몰라도 진행되게 설계된 시스템이 많습니다.

## 첫 접속

1. 서버 리소스팩 요청이 뜨면 허용합니다. 이 서버는 필수팩입니다.
2. 접속하면 `Frontier Compass`와 `QSMP Codex`를 받습니다.
3. 커스텀 제작법은 자동으로 레시피북에 해금됩니다.
4. `QSMP Codex` 일반 우클릭으로 책을 읽습니다.
5. `QSMP Codex`를 들고 웅크린 채 우클릭하면 아이콘 안내 GUI가 열립니다.
6. 나침반을 우클릭하면 전장 방향을 잡습니다.
7. 나침반을 들고 웅크린 채 우클릭하면 봉인 유적 방향을 잡습니다.
8. 바로 전장으로 달리기보다 기본 장비, 방패, 침대, 음식, 동료를 먼저 준비합니다.
9. 밤은 온라인 인원의 50%가 자면 넘어갑니다.

## 전용 리소스팩

QSMP는 바닐라 클라이언트로 접속하지만 서버 전용 리소스팩을 강제로 받습니다.

- 심층암, 흑석, 우는 흑요석, 배럴, 자석석 같은 전장/유적 재료가 더 무겁고 현실적인 질감으로 보입니다.
- Codex, 나침반, 주요 보상 재료가 전용 질감으로 보입니다.
- 버튼/슬롯 UI가 더 어둡고 고급진 톤으로 바뀝니다.
- 전쟁 나팔, 드래곤, 공명석, 패링, vault 연출음이 더 두껍게 들립니다.

리소스팩을 거부하면 서버에 남을 수 없습니다.

## QSMP Codex

명령어를 몰라도 진행 축을 볼 수 있는 인게임 안내책입니다.

- `Warfront`: 전장 나침반 조율
- `Sealed Ruin`: 봉인 유적 나침반 조율
- `Battle Readiness`: 내 Survivor 상태와 메인핸드 Legacy 상태 요약
- `Survivor Level`: 영구 레벨/스탯 확인
- `Legacy Gear`: 들고 있는 장비 성장 확인
- `Enchanting & Anvil`: 10레벨 인챈트와 단일성 인챈트 규칙 확인
- `Outposts`: 거점 제작법 해금과 배치 힌트
- `End Raid`: True Ending + QSMP 공명석 공략 요약
- `Required Resource Pack`: 전용 UI/소리/아이템팩 안내

Codex를 잃어버리면 다시 만들 수 있습니다.

```text
Book + Amethyst Shard + Copper Ingot
```

## 초반 목표

1. 새 청크 방향으로 탐험합니다.
2. Terralith/Terratonic 지형, Dungeons and Taverns 구조물, Explorify/Structory 구조물을 찾습니다.
3. 늑대, 고양이, 말 등 길들일 수 있는 동물을 확보합니다.
4. 동료와 함께 적대 몹을 잡아서 동료 레벨을 올립니다.
5. `Tactical Whistle`을 만들어 동료 역할을 배정합니다.
6. `/survivor`로 내 영구 레벨을 확인합니다.

## 전투 조작

- 방패를 든 상태에서 손 바꾸기 키 기본 `F`: 패링
- 달리는 중 웅크리기 한 번: 구르기
- 구르기 중 짧은 무적 시간이 있습니다.
- 패링 성공 시 피해를 막고 투사체 반사 또는 근접 적 넉백이 발생합니다.
- 성공 타이밍은 소리, 입자, 충격파로 보입니다.

## Survivor Level

플레이어 본체도 영구 레벨을 가집니다. 바닐라 경험치 레벨과 별개입니다.

확인/투자:

- Frontier Codex를 들고 웅크린 채 우클릭합니다.
- `Survivor Level`을 누르면 `Survivor Core` GUI가 열립니다.
- 상단 `XP Routes`는 레이드 밖에서도 XP가 오르는 행동을 보여줍니다.
- 상단 `Battle Readout`은 현재 Might/Endurance/Agility/Wisdom/Command 효과를 수치로 보여줍니다.
- 원하는 스탯 아이콘을 클릭하면 남은 포인트가 바로 투자됩니다.
- 명령으로 열려면 `/survivor`를 사용할 수 있습니다.

- `Might`: 공격 피해
- `Endurance`: 체력/피해 감소
- `Agility`: 구르기 쿨다운, 이동/낙하 보정
- `Wisdom`: 장비 성장 XP
- `Command`: 자원 거점 생산

초반 1회는 GUI의 `Respec`으로 무료 초기화할 수 있습니다.

XP는 레이드만 기다리지 않아도 오릅니다.

- 자연 스폰 적대몹을 잡으면 Survivor XP를 얻습니다.
- 광물, 고대 잔해, 자연 석재 계열, 원목, 완전히 자란 작물을 캐면 XP를 얻습니다.
- 스포너/스폰 알/명령으로 나온 몹과 방금 설치한 블록 재채굴은 XP를 주지 않습니다.
- XP, Might 추가 피해, Endurance 피해 감소는 작은 입자와 사운드로 체감됩니다.

## 인챈트/모루

- 대부분의 인챈트는 최대 10레벨까지 합칠 수 있습니다.
- 수선, 무한, 화염, 섬세한 손길, 친수성, 집전, 다중 발사, 저주 계열은 1레벨 유지입니다.
- 모루의 `Too Expensive` 제한은 풀려 있습니다.
- 기존 장비에 남아 있던 `버그 인챈트` 표기는 인벤토리를 열고 닫거나 아이템을 줍는 과정에서 정리됩니다.
- 정리되면 짧은 안내와 인챈트 테이블 소리가 납니다.

## Legacy Gear

오래 쓰는 장비는 자동으로 `Legacy`가 붙고 성장합니다.

확인:

```text
/legacy
```

- Legacy 대상 장비는 인벤토리에 들어오거나 장착되는 즉시 자동 귀속됩니다.
- `/legacy`는 `Legacy Arsenal` GUI를 열어 들고 있는 장비의 레벨, XP, 킬/작업/레이드
  기록을 보여줍니다.

상위 성장:

- GUI에서 `Refine`을 누르면 네더라이트 조각으로 강화합니다.
- GUI에서 `Awaken`을 누르면 최대 레벨 장비에 Dragon Heart를 바릅니다.
- GUI에서 `Transfer Memory`를 누르면 메인핸드 Legacy가 오프핸드 아이템에
  전송됩니다. 오프핸드의 기존 Legacy 기억은 덮어씁니다.

성장 방법:

- 무기: 직접 공격, 킬
- 도구: 광석, 고대 잔해, 원목 채집
- 방어구: 피해 흡수
- 레이드/유적/드래곤/위더 보상: 장착 장비 전체에 XP 지급

장비 lore와 `Legacy Arsenal` GUI에는 Legacy 레벨, 소유자, 킬/작업/레이드 기록,
피해/공속/채굴/내구/방어 보너스가 퍼센트로 표시됩니다.

강화:

- `refine`: 네더라이트 조각으로 +5까지 강화. +3부터는 Void Scale도 필요하고 실패 확률이 있습니다.
- 실패한 refine은 재료를 잃고 장비 내구도를 깎지만, 장비를 파괴하지 않고 Legacy XP를 조금 줍니다.
- Refine +3 이상 장비는 타격/채굴 때 공명 입자 연출이 생깁니다.
- Legacy Lv.5 이상 장비도 낮은 공명 입자로 성장 체감이 생깁니다.
- `awaken`: 최대 레벨 장비 + Dragon Heart로 각성. 전투 중 Void Burst가 발동할 수 있습니다.
- `transfer`: 메인핸드 장비 기억을 오프핸드 장비에 각인, Memory Shard 필요. 오프핸드 기존 기억은 덮어씁니다.

## 동료 키우기

동료는 길들인 동물 또는 결속한 Happy Ghast입니다.

1. 동물을 길들입니다.
2. 적대 몹과 싸울 때 동료를 근처에 둡니다.
3. 주인이 몹을 죽이면 24블록 안의 가장 가까운 동료가 경험치를 받습니다.
4. 동료가 직접 죽여도 경험치를 받습니다.
5. 동료는 최대 30레벨까지 성장합니다.

동료 확인:

```text
/companion info
```

또는 빈손으로 웅크린 채 내 동료를 우클릭합니다.

## 동료 역할

플레이어 직업은 없습니다. 대신 `Tactical Whistle`로 동료에게 역할을 붙입니다.

- `Vanguard`: 앞라인. 동료 피해 증가, 받는 피해 감소
- `Ranger`: 원거리 지원. 주인이 찍은 대상에게 화살 지원
- `Medic`: 회복 지원. 주인과 주변 동료 회복
- `Gatherer`: 채집/생산. 블록 드롭 보너스, 자원 거점 생산 보너스

사용법:

1. `Tactical Whistle`을 듭니다.
2. 공중이나 블록을 우클릭해 역할을 바꿉니다.
3. 내 동료를 우클릭해 선택한 역할을 배정합니다.

## 동료 보관

`Cryopod`로 동료를 저장하고 다시 꺼낼 수 있습니다.

- 빈 크라이오포드 들고 웅크린 채 내 동료 우클릭: 보관
- 채워진 크라이오포드로 블록 우클릭: 소환
- 소유자만 꺼낼 수 있습니다.

## 자원 거점

자원 거점은 배럴처럼 설치하는 생산 시설입니다.

1. 거점 코어를 만듭니다.
2. 원하는 위치에 설치합니다.
3. 생산물은 해당 배럴 안으로 들어갑니다.
4. 넘친 생산물은 64블록 안의 내 `Warehouse` 또는 공용 `Warehouse`로 이동합니다.
5. Tier II, Tier III 업그레이드 키트로 생산량을 올립니다.

추천 배치:

- `Deep Mine`: y 32 이하
- `Greenhouse`: 위가 밝고 하늘빛이 들어오는 곳
- `Fishery`: 근처에 물이 있는 곳
- `Lumber Camp`: 주변에 나무가 있는 곳
- `Warehouse`: 생산 거점 64블록 안

## 봉인 유적 탐험

구조물 탐험에 공략 목표를 붙인 `QSMPFrontier` 콘텐츠입니다.

1. `Frontier Compass`를 들고 웅크린 채 우클릭합니다.
2. 나침반이 가리키는 유적으로 원정합니다.
3. 주변 청크를 로드하면 작은 폐허와 `Sealed Ruin Vault`가 생깁니다.
4. 폐허 주변의 `Crying Obsidian` ward 3개를 찾습니다.
5. ward 위에는 `End Rod`가 있어 멀리서도 봉인 기둥처럼 보입니다.
6. ward를 깨면 `Ruin Sentinel` 매복과 봉인 파괴 연출이 옵니다.
7. ward 3개와 남은 sentinel을 정리하면 vault 봉인이 풀립니다.
8. vault를 우클릭해서 주변 팀원과 보상을 받습니다.

보상:

- 경험치
- Survivor XP
- 장착 장비 Legacy XP
- 에메랄드
- 경험치 병
- 자수정 조각
- 낮은 확률로 다이아몬드, 메아리 조각, 자원 거점 코어

쿨다운은 90분입니다.

## 야외 전쟁 레이드

`QSMPFrontier`의 메인 레이드입니다.

1. `Frontier Compass`를 우클릭합니다.
2. 나침반이 가리키는 방향으로 원정합니다.
3. 전장 주변 청크를 실제로 로드하면 전장이 자연 지형 위에 건설됩니다.
4. 전장 반경 안에서 15초 머무르면 자동 시작됩니다.
5. 3번의 공격 웨이브, 돌파전, `Iron Tyrant` 보스를 처리합니다.

전장 읽는 법:

- 중앙 의식 링은 집결/교전 기준점입니다.
- 좌/중/우 3개 라인은 깃발과 표준기로 구분됩니다.
- 성문 앞 흑석 기둥과 영혼 랜턴은 최종 돌파 지점입니다.
- 전투 시작, 웨이브, 보스 페이즈, 승리는 타이틀/소리/입자로 크게 표시됩니다.

참가 규칙:

- 전장 주변에 있으면 레이드 참가자로 기록됩니다.
- 중간에 합류해도 참가자로 들어갈 수 있습니다.
- 보스바는 전장 근처 참가자에게 붙습니다.
- 모두 전장을 너무 오래 비우면 레이드는 실패합니다.
- 보상은 전장 근처에 있거나 최근까지 싸운 참가자에게 지급됩니다.

보상:

- 경험치 750
- Survivor XP
- 장착 장비 Legacy XP
- 에메랄드 12개
- 네더라이트 조각 2개
- 랜덤 자원 거점 코어 1개

쿨다운은 180분입니다.

## 트라이얼 챔버

`TrialChamberPro`가 자연 트라이얼 챔버를 반복 콘텐츠로 바꿉니다.

1. 자연 트라이얼 챔버를 찾습니다.
2. 서버가 자동으로 챔버를 등록합니다.
3. 스포너 웨이브는 보스바로 진행도가 보입니다.
4. 볼트와 상자는 플레이어별 보상입니다.
5. 기본 48시간마다 챔버가 리셋됩니다.
6. 챔버 안에서 죽으면 관전 선택지가 뜹니다.

상태 명령:

```text
/tcp stats
/tcp leaderboard <type>
```

비OP에서 막히면 서버 권한 설정 문제입니다. 운영자에게 확인을 요청합니다.

## 엔더 드래곤 레이드

True Ending과 QSMPFrontier 강화가 같이 적용됩니다.

1. Survivor Level, Legacy Gear, 물약, 침대, 활, 블록을 준비합니다.
2. 엔드에 들어가 수정탑을 먼저 정리합니다.
3. 드래곤 체력 65% 이하에서 생기는 공명석 3개를 찾습니다.
4. 공명석이 남아 있으면 드래곤 피해가 25%만 들어가므로, 미니언을 버티며 먼저 파괴합니다.
5. 체력 35% 이하에서 더 먼 공명석 4개가 다시 생깁니다.
6. 처치하면 Dragon Heart, Void Scale, Memory Shard, 확률 Ender Core를 받습니다.

Dragon Heart는 `/legacy awaken`에 씁니다.
Void Scale은 고강화 refine과 Memory Shard 제작에 씁니다.
Memory Shard는 `/legacy transfer`에 씁니다.
Ender Core는 Outpost Upgrade Kit III를 추가 제작하는 데 씁니다.
공명석이 깨지고 보호막이 풀리는 순간이 팀 집중 딜 타이밍입니다.

## 사망과 복구

- 죽으면 사망 지점에 30분짜리 개인 무덤이 생깁니다.
- 아이템은 무덤에 저장됩니다.
- 경험치는 50%만 저장됩니다.
- 본인만 무덤을 열 수 있습니다.
- 30분이 지나면 내용물이 바닥에 떨어집니다.

`/back`, `/home`, `keepInventory`는 기본 흐름에 없습니다. 죽은 곳까지 직접 돌아가야 합니다.
