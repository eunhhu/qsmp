# 콘텐츠 로드맵

목표는 마인크래프트에 아크식 낭만을 붙이는 것입니다.

핵심은 단순히 몹 체력만 늘리는 것이 아닙니다. 친구들이 준비하고, 역할을 나누고, 실패 원인을 공략하고, 오래 쓴 장비와 동료에 애착을 갖게 만드는 구조가 필요합니다.

## 방향성

좋은 반복 루프:

1. 탐험으로 정보 획득
2. 기지에서 준비
3. 동료와 장비 세팅
4. 역할 분담
5. 레이드 도전
6. 보상으로 캐릭터, 장비, 기지 성장
7. 더 어려운 보스/지역 해금

피해야 할 것:

- 체력만 높은 보스
- 랜덤 보상만 많은 파밍
- 혼자 딜찍누 가능한 레이드
- 모든 진행이 명령어와 메뉴에만 갇힌 시스템
- 너무 많은 완성형 RPG 플러그인을 한 번에 넣어서 서버 정체성이 사라지는 것

## 1순위: 현재 레이드 안정화와 재설계

상태: 1차 안정화 적용 완료. 아래 “문제” 중 참가자, 보스바, 이탈, 서버 종료, 몹 누락 watchdog은 `QSMPFrontier`에 반영했습니다. 구조를 별도 `WarfrontSession` 클래스로 완전히 분리하는 작업과 대형 레이드 공략 기믹 확장은 아직 남아 있습니다.

추가 상태: 구조물 탐험용 `Ruin Expedition` 1차도 적용했습니다. 전쟁 레이드보다 작고 자주 도는 공략 콘텐츠로, `Frontier Compass` 웅크린 우클릭 → 봉인 유적 → ward 3개 파괴 → sentinel 매복 → vault 보상 루프입니다.

현재 `QSMPFrontier` 레이드는 방향은 좋지만 구조가 얕습니다.

현재 구조:

- 전장 1곳
- 자동 건설
- 3개 공격 웨이브
- Ravager/Evoker 돌파전
- `Iron Tyrant` 보스
- 전체 보상 지급

기존 문제:

- 상태가 `built`, `active`, `preparing`, `transitionPending` 같은 플래그에 흩어져 있어 버그가 나기 쉽습니다.
- 레이드 참가자 개념이 약했습니다.
- 보스바가 레이드 시작 시 근처 플레이어에게만 붙었습니다.
- 중간 참가, 이탈, 사망, 서버 재시작 처리가 약했습니다.
- 공략 요소가 “몹을 전부 잡는다”에 가깝습니다.

적용된 수정:

- 레이드 참가자와 마지막 전장 체류 시간을 기록합니다.
- 중간 합류 참가자를 보상/보스바 대상에 추가합니다.
- 보스바를 전장 반경 기준으로 계속 동기화합니다.
- 남은 몹을 매 틱 pruning해서 death 이벤트 누락으로 인한 웨이브 정지를 줄였습니다.
- 전장이 비면 grace 이후 실패 처리하고 소환 몹과 보스바를 정리합니다.
- 서버 종료 시 active 여부와 관계없이 전장 상태를 정리합니다.

남은 수정 방향:

- `WarfrontSession` 단위로 레이드 1회를 명확히 관리합니다.
- 참가자, 사망자, 이탈자, 보상 대상, 진행 단계를 별도 세션 객체에 저장합니다.
- 서버 종료/리로드 시 세션을 강제 종료하고 소환 몹과 보스바를 확실히 청소합니다.
- 전장 건설과 레이드 진행을 분리합니다.

추가할 공략 요소:

- 3개 라인 방어: 좌/중/우 중 한 곳이 뚫리면 보스 강화
- 보급 상자: Gatherer 동료나 빠른 플레이어가 회수하면 팀 버프
- 공성 장치: 일정 시간 안에 파괴하지 않으면 성벽/치유지대 비활성
- 지휘관 몹: 살아 있으면 주변 몹 강화
- 보스 방패: 특정 오브젝트를 처리해야 딜 타임 열림
- 부활 제한: 전멸하면 실패, 일부 보상만 지급

이미 추가된 소형 공략 요소:

- 봉인 유적 ward 3개
- vault 봉인/해제 상태
- ward 파괴 시 매복
- ward 누락 watchdog
- 팀 보상 반경

## 2순위: 플레이어 영구 레벨

바닐라 경험치 레벨과 별개로 `Survivor Level`을 둡니다.

추천 구현: 커스텀 `QSMPProgression` 플러그인.

이유:

- 원하는 방향이 일반 RPG 직업보다 SMP 성장에 가깝습니다.
- 기존 동료/전장/거점과 직접 연결하기 쉽습니다.
- 레벨과 보상을 레이드 중심으로 제한해 자동팜 악용을 줄일 수 있습니다.

기본 설계:

- 최대 레벨: 60
- 레벨업마다 스탯 포인트 1
- 10레벨마다 특성 포인트 1
- `/survivor` 또는 책/나침반 GUI로 확인
- 초반 무료 리스펙 1회, 이후 희귀 재료 필요

스탯 후보:

- `Might`: 근접 피해, 방패 패링 보상 증가
- `Endurance`: 최대 체력, 넉백 저항, 무덤 보존 시간 소폭 증가
- `Agility`: 구르기 쿨다운 감소, 이동/낙하 보정
- `Wisdom`: 장비 경험치 획득량, 트라이얼/레이드 보상 품질
- `Command`: 동료 경험치, 동료 역할 효과, 거점 효율

XP 획득처:

- 워프론트 레이드 클리어
- 트라이얼 챔버 클리어
- 엔더 드래곤/위더/월드 보스 처치
- 첫 구조물 발견 보너스
- 거점 업그레이드
- 동료 레벨 milestone

XP를 너무 많이 주면 안 되는 곳:

- 일반 몹 무한 사냥
- 스포너 몹
- 자동 농장
- 낚시/거래 반복

## 3순위: 장비 애착 성장

목표는 “초반 철도끼가 오래 살아남아 전설 장비가 되는 것”입니다.

추천 구현: 커스텀 `QSMPLegacies` 플러그인.

핵심:

- 장비가 처음 의미 있는 행동을 하면 `Legacy`가 붙습니다.
- 장비는 자체 레벨, 경험치, 킬/채굴/레이드 기록을 가집니다.
- 이름, 주인, 제작자, 첫 보스 처치 같은 기록을 lore에 남깁니다.
- 레벨업마다 작은 스탯 또는 특수 perk를 얻습니다.

경험치 예시:

- 무기: 직접 공격, 보스 피해, 패링 직후 반격
- 도구: 자연 블록 채굴, 희귀 광물, 거점 건설
- 방어구: 레이드 피해 흡수, 치명타 생존, 팀원 보호
- 활/쇠뇌: 약점 사격, 공중 목표, 보스 기믹 처리

중요 밸런스:

- 철도끼가 네더라이트 도끼보다 강해질 수는 있어야 합니다.
- 단, 수리 비용/재료/한계돌파가 필요해야 합니다.
- 고급 재료 장비는 기본 성장 효율이 좋고, 오래 쓴 저티어 장비는 특수 perk와 기록으로 살아남게 합니다.

강화 구조:

- `Legacy Level`: 사용 경험치로 상승
- `Refine`: 재료를 넣어 수치 강화
- `Awakening`: 레이드 보스 재료로 특수 perk 해금
- `Memory Transfer`: 오래 쓴 장비의 일부 경험치/기록을 새 장비로 이전

추천 perk:

- `Veteran`: 같은 몹에게 누적 피해 증가
- `Bulwark`: 패링 성공 후 다음 공격 강화
- `Blooded`: 보스에게 준 피해 기록에 따라 보스 피해 증가
- `Field Medic`: 방어구가 주변 아군 회복량 증가
- `Trailblazer`: 도구로 새 구조물 근처 채굴 시 보너스

## 4순위: 드래곤 보스 오버홀

추천: `True Ending`을 먼저 붙이고, 부족한 난이도는 커스텀 레이어로 강화합니다.

근거:

- `True Ending`은 엔더 드래곤에 새 공격, 새 페이즈, 파티클, 보스 음악, 설정 메뉴를 추가합니다.
- Modrinth 기준 `26.1.x`와 서버사이드 데이터팩을 지원합니다.
- 기본 체력은 300 HP라, 성장 서버 후반 보스로는 약할 수 있습니다.

추천 강화 레이어:

- 플레이어 수에 따른 체력/피해 스케일
- 서버 진행도에 따른 추가 페이즈
- 크리스탈 재생성/보호 기믹
- 섬 외곽 오브젝트 점령
- 동료 역할별 상호작용
- 레이드 전용 보상 재료

드래곤 공략 예시:

1. 외곽 수정탑 정찰
2. Phantom Warden 처치로 수정 방어막 해제
3. 지상 돌진/레이저 페이즈 회피
4. 브레스 장판을 Gatherer/Medic 역할로 버티기
5. 40% 이하에서 섬 3곳의 공명석 파괴
6. 마지막 공중 처형 페이즈

보상:

- `Dragon Heart`: 장비 Awakening 재료
- `Void Scale`: 방어구 특성 해금
- `Ender Core`: 거점 Tier IV 또는 창고 확장
- `Memory Shard`: 장비 경험치 이전권

## 외부 플러그인 후보 판단

### True Ending

추천도: 높음

용도:

- 엔더 드래곤 전투 기반 개선
- 데이터팩으로 서버사이드 적용 가능
- 기본 난이도는 커스텀 강화 필요

참고:

- https://modrinth.com/datapack/true-ending

### MythicMobs

추천도: 중간~높음

용도:

- 커스텀 보스, 스킬, 드롭, 페이즈 제작
- 빠르게 다양한 보스를 만들 때 유리

주의:

- 설정 규모가 큽니다.
- 우리 커스텀 플러그인과 역할을 잘 나눠야 합니다.
- “보스 스킬 엔진”으로만 쓰는 것이 가장 깔끔합니다.

참고:

- https://hangar.papermc.io/Lumine/MythicMobs

### AuraSkills

추천도: 중간

용도:

- 빠른 플레이어 스킬/스탯/능력 시스템
- `/skills` GUI와 일반 플레이 활동 기반 XP

주의:

- 직접 스탯 포인트를 찍는 구조보다는 스킬별 자동 성장에 가깝습니다.
- 우리가 원하는 “레이드 중심 영구 레벨”과는 결이 조금 다릅니다.

참고:

- https://wiki.aurelium.dev/auraskills/

### ValhallaMMO

추천도: 중간

용도:

- 무료 대형 RPG 진행 시스템
- 장기 플레이 유도, 직업/스킬/제작/전투 오버홀

주의:

- 서버 전체 규칙을 크게 바꿉니다.
- QSMP만의 성장 구조를 만들려면 오히려 과할 수 있습니다.

참고:

- https://modrinth.com/plugin/valhallammo

### MMOCore/MMOItems

추천도: 낮음~중간

용도:

- 클래스, 속성 포인트, 스킬 트리, 아이템 요구치까지 완성형 MMORPG 구축

주의:

- 원하는 것을 많이 해주지만 너무 무겁습니다.
- 소규모 친구 SMP에는 관리 비용이 큽니다.

참고:

- https://docs.phoenixdevt.fr/mmocore/features/attributes.html
- https://docs.phoenixdevt.fr/mmocore/general/commands.html

### EcoItems / Libreforge item levels

추천도: 중간

용도:

- 커스텀 아이템 레벨, XP 요구량, 레벨업 효과

주의:

- “모든 바닐라 장비가 개인 장비로 성장”하는 감성은 커스텀이 더 잘 맞습니다.
- 커스텀 아이템 중심 서버로 갈 때 더 적합합니다.

참고:

- https://plugins.auxilor.io/effects/item-levels

## 추천 결론

가장 좋은 길:

1. 현재 `QSMPFrontier` 레이드 버그 안정화
2. `QSMPProgression`으로 플레이어 영구 레벨 추가
3. `QSMPLegacies`로 장비 경험치/기록/각성 추가
4. `True Ending` 데이터팩 추가
5. 드래곤 약하면 `QSMPDragon` 커스텀 강화 레이어 추가
6. 필요하면 MythicMobs를 보스 스킬 엔진으로 제한 도입

이 방식이면 서버가 플러그인 묶음이 아니라 하나의 아크식 SMP처럼 느껴집니다.

## 첫 구현 단위

가장 먼저 할 일:

1. 레이드 세션 구조 재작성: 부분 완료, 별도 클래스 분리는 남음
2. 워프론트 보스바/참가자/이탈/보상 버그 수정: 1차 완료
3. 봉인 유적 소형 공략 루프: 1차 완료
4. 레이드/유적 보상을 `Survivor XP`와 `Legacy XP`로 연결
5. `Survivor Level` 1~30 MVP
6. 장비 `Legacy Level` 1~10 MVP
7. True Ending 설치와 강화 가능성 테스트

이 순서가 맞습니다. 레이드가 불안정한 상태에서 성장 시스템을 붙이면, 보상과 진행 데이터까지 같이 꼬입니다.
