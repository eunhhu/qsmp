# 콘텐츠 로드맵

목표는 마인크래프트에 아크식 낭만을 붙이는 것입니다.

핵심은 단순히 몹 체력만 늘리는 것이 아닙니다. 친구들이 준비하고, 역할을 나누고, 실패 원인을 공략하고, 오래 쓴 장비와 동료에 애착을 갖게 만드는 구조가 필요합니다.

## 방향성

좋은 반복 루프:

1. 탐험으로 정보 획득
2. 기지에서 준비
3. 동료와 장비 세팅
4. 역할 분담
5. 레이드 도전
6. 보상으로 캐릭터, 장비, 기지 성장
7. 더 어려운 보스/지역 해금

피해야 할 것:

- 체력만 높은 보스
- 랜덤 보상만 많은 파밍
- 혼자 딜찍누 가능한 레이드
- 모든 진행이 명령어와 메뉴에만 갇힌 시스템
- 너무 많은 완성형 RPG 플러그인을 한 번에 넣어서 서버 정체성이 사라지는 것

## 이번 구현: 인게임 안내와 연출 레이어

상태: `QSMPFrontier 1.4.0` 적용 완료.

이번 작업은 커맨드 암기 대신 게임 안의 물건과 장소로 흐름을 알게 만드는 쪽에 집중했습니다.

적용:

- 첫 접속 `QSMP Codex` 지급
- Codex 일반 우클릭 책 안내
- Codex 웅크린 우클릭 아이콘 GUI
- Codex `Battle Readiness`로 Survivor/Legacy 상태를 한 화면 요약
- Codex `Enchanting & Anvil`/`Optional Dragon Music` 안내 추가
- 커스텀 제작법 자동 해금
- Survivor Core `XP Routes`/`Battle Readout` 정보 패널
- Survivor XP, Might 추가 피해, Endurance 피해 감소 인게임 피드백
- 패링/구르기/회피 성공 연출
- 동료 역할 배정, Ranger 사격, Medic 회복 연출
- 자원 거점 설치/업그레이드/생산 연출
- 봉인 유적 신호, ward 파괴, vault 해제/보상 연출
- 워프론트 전장 중앙 링, 라인 깃발, 성문 기둥, 카운트다운/웨이브/보스 페이즈/승리 연출
- 드래곤 각성, 공명석, 보호막 붕괴, 처치 연출
- Legacy Lv.5 저강도 공명, Refine +3 강공명/번개, 레벨업 입자 강화
- 인챈트 상한/버그 인챈트 lore 주기 정리와 플레이어 피드백
- 필수 QSMP 리소스팩: 현실풍 텍스처, UI sprite, 사운드 레이어

남은 방향:

- 전장 라인별 실패/성공이 보스 강화에 직접 연결되게 만들기
- 유적 종류를 1종에서 여러 테마와 퍼즐로 확장하기
- 엔드 아레나를 Nullscape 위에 별도 웅장 구조로 더 크게 조각하기
- 플레이어 클라이언트로 Codex GUI 클릭 흐름과 실제 전투 연출을 체감 QA하기

## 1순위: 현재 레이드 안정화와 재설계

상태: 1차 안정화 적용 완료. 아래 “문제” 중 참가자, 보스바, 이탈, 서버 종료, 몹 누락 watchdog은 `QSMPFrontier`에 반영했습니다. 구조를 별도 `WarfrontSession` 클래스로 완전히 분리하는 작업과 대형 레이드 공략 기믹 확장은 아직 남아 있습니다.

추가 상태: 구조물 탐험용 `Ruin Expedition` 1차도 적용했습니다. 전쟁 레이드보다 작고 자주 도는 공략 콘텐츠로, `Frontier Compass` 웅크린 우클릭 → 봉인 유적 → ward 3개 파괴 → sentinel 매복 → vault 보상 루프입니다.

현재 `QSMPFrontier` 레이드는 방향은 좋지만 구조가 얕습니다.

현재 구조:

- 전장 1곳
- 자동 건설
- 3개 공격 웨이브
- Ravager/Evoker 돌파전
- `Iron Tyrant` 보스
- 전체 보상 지급

기존 문제:

- 상태가 `built`, `active`, `preparing`, `transitionPending` 같은 플래그에 흩어져 있어 버그가 나기 쉽습니다.
- 레이드 참가자 개념이 약했습니다.
- 보스바가 레이드 시작 시 근처 플레이어에게만 붙었습니다.
- 중간 참가, 이탈, 사망, 서버 재시작 처리가 약했습니다.
- 공략 요소가 “몹을 전부 잡는다”에 가깝습니다.

적용된 수정:

- 레이드 참가자와 마지막 전장 체류 시간을 기록합니다.
- 중간 합류 참가자를 보상/보스바 대상에 추가합니다.
- 보스바를 전장 반경 기준으로 계속 동기화합니다.
- 남은 몹을 매 틱 pruning해서 death 이벤트 누락으로 인한 웨이브 정지를 줄였습니다.
- 전장이 비면 grace 이후 실패 처리하고 소환 몹과 보스바를 정리합니다.
- 서버 종료 시 active 여부와 관계없이 전장 상태를 정리합니다.

남은 수정 방향:

- `WarfrontSession` 단위로 레이드 1회를 명확히 관리합니다.
- 참가자, 사망자, 이탈자, 보상 대상, 진행 단계를 별도 세션 객체에 저장합니다.
- 서버 종료/리로드 시 세션을 강제 종료하고 소환 몹과 보스바를 확실히 청소합니다.
- 전장 건설과 레이드 진행을 분리합니다.

추가할 공략 요소:

- 3개 라인 방어: 좌/중/우 중 한 곳이 뚫리면 보스 강화
- 보급 상자: Gatherer 동료나 빠른 플레이어가 회수하면 팀 버프
- 공성 장치: 일정 시간 안에 파괴하지 않으면 성벽/치유지대 비활성
- 지휘관 몹: 살아 있으면 주변 몹 강화
- 보스 방패: 특정 오브젝트를 처리해야 딜 타임 열림
- 부활 제한: 전멸하면 실패, 일부 보상만 지급

이미 추가된 소형 공략 요소:

- 봉인 유적 ward 3개
- vault 봉인/해제 상태
- ward 파괴 시 매복
- ward 누락 watchdog
- 팀 보상 반경

## 2순위: 플레이어 영구 레벨

상태: `QSMPFrontier` 통합 MVP 적용 완료. 별도 `QSMPProgression`
플러그인으로 분리하지는 않았지만 데이터는 `plugins/QSMPFrontier/progression.yml`에
분리 저장합니다.

바닐라 경험치 레벨과 별개로 `Survivor Level`을 둡니다.

추천 구현: 커스텀 `QSMPProgression` 플러그인.

이유:

- 원하는 방향이 일반 RPG 직업보다 SMP 성장에 가깝습니다.
- 기존 동료/전장/거점과 직접 연결하기 쉽습니다.
- 레벨과 보상을 레이드 중심으로 제한해 자동팜 악용을 줄일 수 있습니다.

기본 설계:

- MVP 최대 레벨: 30
- 레벨업마다 스탯 포인트 1
- 10레벨마다 특성 포인트 1 저장
- Frontier Codex 또는 `/survivor`로 `Survivor Core` GUI를 열어 확인/투자
- `Might`, `Endurance`, `Agility`, `Wisdom`, `Command` 아이콘 클릭으로 포인트 투자
- `Respec` 아이콘은 1회 무료, 이후 메아리 조각 1개 필요

스탯 후보:

- `Might`: 플레이어 공격 피해 증가
- `Endurance`: 최대 체력 증가, 받는 피해 감소
- `Agility`: 구르기 쿨다운 감소, 이동/낙하 보정
- `Wisdom`: 장비 Legacy XP 획득량 증가
- `Command`: 자원 거점 생산 효율 증가

XP 획득처:

- 워프론트 레이드 클리어: 적용
- 봉인 유적 vault claim: 적용
- 엔더 드래곤/위더 처치: 적용
- 거점 업그레이드: 적용
- 트라이얼 챔버 클리어: 미연결
- 첫 구조물 발견 보너스: 미구현
- 동료 레벨 milestone: 미구현
- XP 경로/전투 스탯 GUI 표시: 적용
- 일반 행동 XP 피드백: 적용

XP를 너무 많이 주면 안 되는 곳:

- 일반 몹 무한 사냥
- 스포너 몹
- 자동 농장
- 낚시/거래 반복

## 3순위: 장비 애착 성장

상태: `QSMPFrontier` 통합 MVP 적용 완료. 별도 `QSMPLegacies`
플러그인으로 분리하지는 않았고, 장비의 PDC와 lore에 직접 `Legacy` 데이터를
저장합니다.

목표는 “초반 철도끼가 오래 살아남아 전설 장비가 되는 것”입니다.

추천 구현: 커스텀 `QSMPLegacies` 플러그인.

핵심:

- 대상 장비가 인벤토리에 들어오거나 장착/핫바 이동/픽업되면 `Legacy`가 자동으로 붙습니다.
- 장비는 자체 레벨, 경험치, 킬/작업/레이드 기록을 가집니다.
- 소유자와 기록을 lore에 남깁니다.
- 무기는 Legacy 레벨에 따라 최종 피해/공속/내구 보호가 증가합니다.
- 도구는 Legacy 레벨에 따라 채굴 속도/공속/내구 보호가 증가합니다.
- 방어구는 Legacy 레벨에 따라 받는 피해와 내구 소모를 줄입니다.
- `/legacy` 또는 Codex의 `Legacy Gear`는 `Legacy Arsenal` GUI를 열어
  확인, 강화, 각성, 기억 전송을 처리합니다.
- `/legacy bind`는 호환용 no-op 안내로만 남기며 일반 플레이 흐름에서는 쓰지 않습니다.

경험치 예시:

- 무기: 직접 공격, 킬, 전장/유적 몹 전투
- 도구: 광석, 고대 잔해, 원목 채집
- 방어구: 피해 흡수
- 활/쇠뇌/삼지창/메이스: 무기와 같은 전투 XP
- 레이드/유적/드래곤/위더 보상 XP: 장착 장비에 분배

중요 밸런스:

- 철도끼가 네더라이트 도끼보다 강해질 수는 있어야 합니다.
- 단, 수리 비용/재료/한계돌파가 필요해야 합니다.
- 고급 재료 장비는 기본 성장 효율이 좋고, 오래 쓴 저티어 장비는 특수 perk와 기록으로 살아남게 합니다.

강화 구조:

- `Legacy Level`: 사용 경험치로 상승, MVP 최대 10
- `Refine`: 적용. `/legacy refine`, 네더라이트 조각 비용, +3부터 Void Scale, 실패 확률, 최대 +5
- `Refine 실패`: 적용. 재료 소모, 내구도 손상, 장비 파괴 방지, 실패 XP 지급
- `Legacy 보너스 표기`: 적용. lore/GUI에 피해, 공속, 채굴속도, 내구 보호, 방어 보너스 표시
- `Refine/성장 연출`: 적용. Lv.5 저강도 공명, +3 이상 타격/채굴 공명과 번개, 각성 장비 Void Burst
- `Awakening`: 적용. `/legacy awaken`, 최대 레벨 장비 + Dragon Heart 필요
- `Memory Transfer`: 적용. `/legacy transfer`, 메인핸드 원본 기억을 오프핸드 장비에 각인, Memory Shard 필요, 기존 오프핸드 기억 덮어쓰기

추천 perk:

- `Veteran`: 같은 몹에게 누적 피해 증가
- `Bulwark`: 패링 성공 후 다음 공격 강화
- `Blooded`: 보스에게 준 피해 기록에 따라 보스 피해 증가
- `Field Medic`: 방어구가 주변 아군 회복량 증가
- `Trailblazer`: 도구로 새 구조물 근처 채굴 시 보너스

## 4순위: 드래곤 보스 오버홀

상태: `True Ending` datapack `1.1.4d` 설치 및 `datapacks.lock` 고정 완료.
기본 강화 가능성 테스트는 서버 기동과 데이터팩 활성 확인까지 완료했습니다.
`QSMPFrontier` 커스텀 강화 레이어 MVP도 적용했습니다.

추천: `True Ending`을 보스전 기준으로 유지하고, 부족한 난이도는 커스텀 레이어로 강화합니다.

근거:

- `True Ending`은 엔더 드래곤에 새 공격, 새 페이즈, 파티클, 보스 음악, 설정 메뉴를 추가합니다.
- Modrinth 기준 `26.1.x`와 서버사이드 데이터팩을 지원합니다.
- 기본 체력은 300 HP라, 성장 서버 후반 보스로는 약할 수 있습니다.

추천 강화 레이어:

- 플레이어 수에 따른 체력/피해 스케일: 적용
- 서버 진행도에 따른 추가 페이즈: 체력 65%, 35% 공명 페이즈 적용
- 크리스탈 재생성/보호 기믹: 공명석 보호막으로 대체 적용
- 섬 외곽 오브젝트 점령: 공명석 파괴 목표로 1차 적용
- 동료 역할별 상호작용
- 레이드 전용 보상 재료: Dragon Heart, Void Scale, Memory Shard, Ender Core 적용

드래곤 공략 예시:

1. 외곽 수정탑과 공명석 후보 위치 정찰
2. True Ending 드래곤 패턴 회피
3. 65% 이하에서 공명석 3개 파괴
4. 보호막 동안 들어오는 미니언 정리
5. 35% 이하에서 더 먼 공명석 4개 파괴
6. 마지막 페이즈 화력 집중

보상:

- `Dragon Heart`: 장비 Awakening 재료
- `Void Scale`: Refine +3 이상 재료, Memory Shard 제작 재료
- `Ender Core`: Outpost Upgrade Kit III 추가 제작법
- `Memory Shard`: 장비 기억 전송권

## 외부 플러그인 후보 판단

### True Ending

추천도: 높음

용도:

- 엔더 드래곤 전투 기반 개선
- 데이터팩으로 서버사이드 적용 가능
- 기본 난이도는 커스텀 강화 필요

참고:

- https://modrinth.com/datapack/true-ending

### MythicMobs

추천도: 중간~높음

용도:

- 커스텀 보스, 스킬, 드롭, 페이즈 제작
- 빠르게 다양한 보스를 만들 때 유리

주의:

- 설정 규모가 큽니다.
- 우리 커스텀 플러그인과 역할을 잘 나눠야 합니다.
- “보스 스킬 엔진”으로만 쓰는 것이 가장 깔끔합니다.

참고:

- https://hangar.papermc.io/Lumine/MythicMobs

### AuraSkills

추천도: 중간

용도:

- 빠른 플레이어 스킬/스탯/능력 시스템
- `/skills` GUI와 일반 플레이 활동 기반 XP

주의:

## 추천 결론

가장 좋은 길:

1. 현재 `QSMPFrontier` 레이드 버그 안정화
2. `QSMPProgression`으로 플레이어 영구 레벨 추가
3. `QSMPLegacies`로 장비 경험치/기록/각성 추가
4. `True Ending` 데이터팩 추가
5. 드래곤 약하면 `QSMPDragon` 커스텀 강화 레이어 추가
6. 필요하면 MythicMobs를 보스 스킬 엔진으로 제한 도입

이 방식이면 서버가 플러그인 묶음이 아니라 하나의 아크식 SMP처럼 느껴집니다.

## 첫 구현 단위

가장 먼저 할 일:

1. 레이드 세션 구조 재작성: 부분 완료, 별도 클래스 분리는 남음
2. 워프론트 보스바/참가자/이탈/보상 버그 수정: 1차 완료
3. 봉인 유적 소형 공략 루프: 1차 완료
4. 레이드/유적 보상을 `Survivor XP`와 `Legacy XP`로 연결: 완료
5. `Survivor Level` 1~30 MVP: 완료
6. 장비 `Legacy Level` 1~10 MVP: 완료
7. 장비 `Refine`/`Awakening`/`Memory Transfer`: 완료
8. True Ending 설치와 강화 가능성 테스트: 설치/활성 확인 완료
9. 드래곤 커스텀 강화 레이어 MVP: 완료
10. QSMP Codex/GUI/제작법 자동 해금: 완료
11. 전투/동료/거점/유적/워프론트/드래곤 연출 레이어: 완료

이 순서가 맞습니다. 레이드가 불안정한 상태에서 성장 시스템을 붙이면, 보상과 진행 데이터까지 같이 꼬입니다.
